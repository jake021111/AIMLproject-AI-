3. 구축한 학습 파이프라인 (ai/ 디렉터리)
----------------------------------------------------------

scripts/oversample_critical.py  veryHigh 클래스(계단/에스컬레이터/엘리베이터/점자블록) 오버샘플링

validate.py                  mAP + veryHigh 클래스 recall 검증 스크립트
requirements.txt, README.md, .gitignore

5. AI Hub 186 실제 라벨 스키마 조사 (2026-09-20)
----------------------------------------------------------
- 라벨 JSON 구조: {"images": {file_name, width, height},
                    "annotations": [{"id": "rectangle_N"|"polygon_N",
                    "category_id": <str>, "segmentation": [[x,y],...]}]}
- rectangle: segmentation에 대각 꼭짓점 2개 (bbox)
- polygon: 다각형 꼭짓점 목록 -> min/max로 bbox 변환

- "_s" 접미사 파일의 정체를 실제 데이터로 확인함:
  객체 좌표가 아니라 촬영 메타데이터(GPS, 촬영 주소, 날씨, 주/야간 등).
  학습에는 불필요 -> 사용하지 않음.

- 15-class 체계와 실제 category_id 매핑 확정:
  chair          <- chair_one, chair_multi, chair_back, chair_circular, chair_handle
  pillar         <- pillar
  trash_can      <- trash_can
  stairs         <- stair_normal, stair_broken
  elevator_door  <- lift_door, lift
  door           <- door_normal
  vending_machine<- beverage_vending_machine
  tactile_paving <- brailleblock_dot, brailleblock_line (+ broken 2종)
  signage_stand  <- direction_sign_exit/right/left/straight
  counter        <- reception_desk (신규 해결! 기존엔 매칭 데이터 없다고 판단했었음)

- 여전히 해결 못한 클래스 (AI Hub 186에 대응 카테고리 없음):
  escalator, automatic_door, kiosk
  -> 직접 촬영 + 수동 라벨링으로 보강 필요 (추후 과제)
  -> kiosk는 number_ticket_machine(번호표 발급기, 702건)이 가장 근접하지만
     개념이 달라 확정 매핑은 보류함
